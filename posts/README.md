# Post templates — APIS Media

SVG-шаблоны для блог-обложек, OG-изображений, постов в соцсети и сториз. На бренд-градиенте с кубом и логотипом.

## Файлы

| Файл | Размер | Для чего |
|---|---|---|
| `post-1200x630.svg` | 1200 × 630 | OG-image, Twitter / X, LinkedIn, шапка блог-поста |
| `post-1080x1080.svg` | 1080 × 1080 | Instagram, VK, OK, Telegram-каналы |
| `post-1080x1920.svg` | 1080 × 1920 | Instagram Stories / Reels, TikTok, VK Clips |

Все три используют один дизайн-язык: радиальный бренд-градиент, точечная решётка, изометрический куб APIS, типографика Inter + JetBrains Mono.

## Как редактировать

### В Figma
1. `File → Import` (или просто перетащите SVG на canvas)
2. Каждый текст-элемент станет отдельным слоем — клик и редактируй
3. Все редактируемые поля помечены `id="EDIT-*"`:

| ID | Что редактировать |
|---|---|
| `EDIT-BRAND-NAME` | «ЭЙПИСМЕДИА» — название компании |
| `EDIT-PRODUCT` | «ЕС-ПРОФОСМОТР · МИС» — продукт |
| `EDIT-META` | Дата / номер выпуска / любой служебный текст |
| `EDIT-KICKER` | «§ 02 · РЕГУЛЯТОРИКА» — рубрика |
| `EDIT-TITLE` | Заголовок поста (несколько `<tspan>` под строки) |
| `EDIT-DEK` | Подзаголовок / описание |
| `EDIT-URL` | `prof-mo.site` или конкретный URL поста |
| `EDIT-FOOTER` | «APIS MEDIA · 2026» — копирайт |

### В Adobe Illustrator / Sketch / Inkscape
Все три открывают SVG нативно. Структура групп сохраняется.

### Прямо в текстовом редакторе
Можно открыть `.svg` как обычный текст и заменить контент в `<text>...</text>`. Удобно для автоматизации (например, генератор постов из markdown через шаблон).

## Что внутри каждого шаблона

```
1. Фон
   ├── Радиальный бренд-градиент (#060D1B → #0B1A3A → #0542AC)
   ├── Точечная решётка (Pattern dots)
   └── Soft glow в углу

2. Top bar
   ├── Мини-куб (логотип APIS, белый wireframe)
   ├── Текст «ЭЙПИСМЕДИА»
   └── Текст «ЕС-ПРОФОСМОТР · МИС»

3. Title block
   ├── § рубрика (мелкая моноширинная)
   ├── Большой заголовок (Inter Bold)
   └── Подзаголовок (Inter Regular, opacity 0.72)

4. Декоративный куб
   └── Большой изометрический куб с градиентными гранями,
       половинной прозрачности — как фоновый акцент

5. Bottom bar
   ├── Тонкая линия-разделитель
   ├── URL (prof-mo.site)
   └── Копирайт-метка
```

## Бренд-цвета (для редактирования градиентов)

| Назначение | HEX |
|---|---|
| Самый тёмный (база градиента) | `#060D1B` |
| Средний тёмный | `#0B1A3A` |
| Бренд-тёмный (start градиента) | `#0542AC` |
| Бренд-средний | `#2167E0` |
| Бренд-светлый (акценты) | `#7DA8FF` |

## Шрифты

Используются **Inter** (тело, заголовки) и **JetBrains Mono** (рубрики, моноширинные элементы). Оба бесплатные, Google Fonts.

Если хотите ROOM (фирменный шрифт APIS из бренд-бука) — замените `font-family="Inter, sans-serif"` на `font-family="Room, Inter, sans-serif"` и убедитесь, что шрифт установлен в системе перед экспортом в PNG.

## Экспорт в PNG для соцсетей

В Figma / Illustrator:
1. Выделите весь SVG как фрейм
2. Export → PNG → 1× / 2×
3. Готово

Через CLI (если есть `rsvg-convert`):
```bash
rsvg-convert -w 1200 post-1200x630.svg > post.png
rsvg-convert -w 1080 post-1080x1080.svg > post-square.png
rsvg-convert -w 1080 post-1080x1920.svg > post-story.png
```

Через Inkscape:
```bash
inkscape post-1200x630.svg --export-type=png --export-width=1200
```

## Идеи для серии постов

Один шаблон → много постов разных типов:

| Тип поста | Категория (kicker) | Цвет акцента |
|---|---|---|
| Новости регуляторики | `§ NN · РЕГУЛЯТОРИКА` | brand-light `#7DA8FF` |
| Технический разбор | `§ NN · ЕГИСЗ / СЭМД` | brand-mid `#2167E0` |
| Кейсы клиник | `§ NN · КЕЙС` | white |
| Гайды и инструкции | `§ NN · ГАЙД` | brand-light `#7DA8FF` |
| Анонсы продуктов | `§ NN · РЕЛИЗ` | bright accent |

Можно делать **серию по 9 постов из одной статьи блога** — заголовок, цитата, цифра, кейс — каждый со своим §-номером.

## Что не входит в шаблоны

- ❌ Photo placeholder (если нужны фото-обложки — отдельный шаблон)
- ❌ QR-код (легко добавить отдельным `<image>` или `<g>`)
- ❌ Анимации (это статика, для анимированных stories используйте After Effects / Canva)
