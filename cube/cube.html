APIS Media — изометрический куб

Standalone-реализация. Один CSS-файл + чистый HTML с inline-SVG. Без сборщиков, без зависимостей. Открывается в любом современном браузере.

§ 01 · Четыре варианта фигуры

shape: hex / cube / solid / cluster

hex

Основной знак — шестиугольник + Y + 3 грани с градиентом.

orbit · md · brand

cube

Полный wireframe — все 12 рёбер. 3 задних — пунктиром.

draw · md · brand

solid

Заливки доминируют. Тонкие линии-стыки. Без точек-вершин.

static · md · brand

cluster

3 мини-куба под 120°. Для семейства продуктов.

draw · md · brand

§ 02 · Тоны на тёмном фоне

tone: light / dark / mono

tone="light"

На тёмном — края светлеют (blue-300), грани в screen-blend.

orbit · md · light

tone="dark"

Внешние рёбра — самый тёмный navy, отлично на бумаге.

static · md · dark

tone="mono"

Одноцветный, без заливок. Для печати, штампов, фавикона.

static · md · mono

§ 03 · Как подключить

3 шага

<!-- 1. Подключить cube.css в <head> -->
<link rel="stylesheet" href="cube.css">

<!-- 2. HTML-разметка куба -->
<div class="iso iso--md iso--orbit iso--shape-hex">
  <svg viewBox="-120 -120 240 240">
    <defs> ...три линейных градиента (top, right, left)... </defs>
    <g class="iso__group">
      <!-- 3 face paths + 6 outer edges + 3 inner Y + 7 vertices -->
    </g>
    <!-- (только для orbit) 3 орбитальные частицы с SMIL -->
  </svg>
</div>

<!-- 3. Готово -->

Классы-модификаторы:
iso--xs|sm|md|lg|xl — размер
iso--static|draw|orbit — режим анимации
iso--brand|light|dark|mono — тон (для разных подложек)
iso--shape-hex|cube|solid|cluster — вариант фигуры
