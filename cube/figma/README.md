# APIS Cube — для импорта в Figma

Четыре SVG-файла с фирменным изометрическим кубом APIS Media. Готовы к импорту, со структурированными группами и понятными именами слоёв.

## Файлы

| Файл | Что внутри | Когда использовать |
|---|---|---|
| `cube-hex.svg` ★ | Основной логотип-знак | Hero, шапка, маркеры секций — везде по умолчанию |
| `cube-cube.svg` | Полный wireframe (12 рёбер, 3 пунктирных «задних») | Тех-разделы, документация, API |
| `cube-solid.svg` | Сильные градиентные заливки + тонкие линии | Премиум-моменты, награды, KV |
| `cube-cluster.svg` | 3 мини-куба в трефойл-расстановке | Страница «семейство продуктов» |

## Как импортировать в Figma

### Способ 1 — Drag & Drop
Просто перетащите SVG-файл из проводника прямо в Figma-canvas. Появится фрейм со всеми слоями.

### Способ 2 — File → Import
1. `File → Place Image…` (или `Cmd/Ctrl+Shift+K`)
2. Выберите нужный `.svg`
3. Клик по канвасу — куб появится с сохранёнными группами

### Способ 3 — Paste код
1. Откройте `.svg` в текстовом редакторе
2. Скопируйте всё содержимое
3. В Figma — `Cmd/Ctrl+V` прямо на канвас
4. Figma распарсит SVG и создаст слои

## Структура слоёв в Figma после импорта

```
APIS Cube - Hex                  ← группа верхнего уровня
├── Faces                         ← подгруппа: 3 грани с градиентом
│   ├── Top Face
│   ├── Right Face
│   └── Left Face
├── Outer Edges                   ← подгруппа: 6 рёбер шестиугольника
│   ├── Edge 01 Top Right Diag
│   ├── Edge 02 Right
│   ├── … (всего 6)
│   └── Edge 06 Top Left Diag
├── Inner Y                       ← подгруппа: внутренние 3 ребра
│   ├── Y Up
│   ├── Y Lower Right
│   └── Y Lower Left
└── Vertices                      ← подгруппа: 7 точек-вершин
    ├── V Top
    ├── … (всего 7)
    └── V Center
```

Можно скрывать / показывать любую подгруппу через Figma layer panel.

## Что важно знать про градиенты

В SVG используются **линейные градиенты** (`<linearGradient>`):
- `top` — для верхней грани (свет сверху)
- `right` — для правой грани
- `left` — для левой грани

Figma корректно импортирует их как **Linear Fill** на формах. Цвета-стопы:
- `#7DA8FF` opacity 0.55 → `#2167E0` opacity 0.32 → `#0542AC` opacity 0.18 — для верхней грани
- (другие — со своим балансом для остальных граней)

Если хотите изменить градиент в Figma — выберите грань, в правой панели Fill → клик по градиенту → редактируйте стопы.

## Бренд-цвета (для редактирования)

| Применение | HEX |
|---|---|
| Внешние рёбра (outer) | `#0542AC` |
| Внутренние Y / центр / акценты | `#7DA8FF` |
| Средний синий (в градиентах) | `#2167E0` |

## Размер по умолчанию

ViewBox `-120 -120 240 240`, экспортированный размер **400×400 px**. В Figma можно масштабировать без потери качества — это вектор.

Минимальный читаемый размер: **25 мм / ~95 px** (рекомендация бренд-бука APIS).

## Что НЕ переносится из веб-версии

Figma игнорирует CSS-анимации и SMIL — поэтому в импортированных файлах **нет**:
- Сборки по линиям при появлении
- Постоянного вращения куба (orbit-mode)
- Орбитальных частиц вокруг куба
- Fade-in граней

Это нормально: Figma — статический инструмент. Для интерактивных версий используйте `cube.html` / Astro-компонент.

## Если нужны PNG-экспорты

В Figma:
1. Выделите группу `APIS Cube`
2. В правой панели — `Export` 
3. Выберите формат (PNG / JPG / WebP) и масштаб (1×, 2×, 3×)
4. `Export selected`

Рекомендованные размеры:
- Фавикон: **64×64** (mono-вариант лучше)
- App icon: **256×256**, **512×512**
- Презентация: **1024×1024** или **2048×2048**

## Если нужно векторизовать в Illustrator / Sketch

Те же SVG-файлы открываются в Adobe Illustrator (`File → Open`) и Sketch (`File → Open`). Структура групп сохраняется.
