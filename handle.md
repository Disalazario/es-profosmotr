## 4 · IsoCube — фирменный знак

**4 варианта формы** через prop `shape`:

| shape | Когда |
|---|---|
| `hex` ★ | **Основной знак**. Default. Везде в production. |
| `cube` | Полный 12-рёберный wireframe. Тех-разделы. |
| `solid` | Сильные градиентные заливки. Премиум-страницы. |
| `cluster` | 3 мини-куба 120°. Семейство продуктов. |

### API

```astro
<IsoCube
  shape="hex"          ★ ВСЕГДА явно, не полагаться на default
  size="xs|sm|md|lg|xl"
  mode="static|draw|orbit"
  tone="brand|light|dark|mono"
  parallax={false}     осторожно — конфликт со спином
  delay={0}            мс, для каскада
/>
```

### Переопределение размера

`.iso--xl` фиксирован 400px. Чтобы сделать больше/меньше — переопределить CSS-переменную:

```html
<div style="--cube-xl: 560px;">
  <IsoCube shape="hex" size="xl" ... />
</div>
```

Так сделан hero-watermark.


### Что НЕЛЬЗЯ менять в hero без понимания

1. **`&nbsp;` между «информационная» и «система»** — иначе «система» уходит на отдельную строку (баг-репорт от пользователя)
2. **`--cube-xl: 560px` через inline style** — без этого куб будет 400px, слишком мелкий
3. **`relative z-10` на заголовке** — гарантия что текст над кубом
4. **`absolute inset-0` на кубе ВНУТРИ контентного контейнера** (а не секции) — иначе центр считается от секции с асимметричным padding, и куб не по центру текста
5. **`sm:justify-self-end` / `sm:justify-self-start` на кнопках** — обеспечивает что щель между ними по центру (= под центром куба)

## 10 · 🐛 Известные грабли

### Куб «не по центру»
**Симптом:** пользователь жалуется что куб смещён.
**Причина 1:** `absolute inset-0` поставлено на саму `<section>` с асимметричным `pt-12 pb-20 ...` padding. Центр секции ≠ центру контентного блока.
**Фикс:** ставь `absolute inset-0` ВНУТРИ контентного контейнера, а не на секции.
**Причина 2:** не переопределён `--cube-xl` — куб остаётся 400px.
**Фикс:** `style="--cube-xl: 560px"` на обёртке куба.

### «Система» уходит на отдельную строку в заголовке
**Симптом:** заголовок ломается на 3 строки вместо 2.
**Причина:** слова «информационная» и «система» переносятся отдельно.
**Фикс:** **`&nbsp;` между «информационная» и «система»** — связывает их.

### Щель между CTA-кнопками не по центру
**Симптом:** при `flex justify-center gap-3` щель смещена потому что у кнопок разные ширины.
**Фикс:** `grid grid-cols-2 max-w-2xl mx-auto`, левая кнопка `justify-self-end`, правая `justify-self-start`. Щель = stык колонок = центр.

### Tilda-стиль появляется при первой попытке дизайна
**Симптом:** generic SaaS-блоки.
**Лечение:** перечитать §8 (DON'T) этого файла.

### Орбитальные частицы куба крутятся вокруг непонятной точки
**Симптом:** при `mode="orbit"` точки летают где-то сбоку, не вокруг куба.
**Причина:** CSS-rotate на группе с `transform-box: view-box` неоднозначно работает в браузерах.
**Фикс:** В IsoCube.astro орбита уже сделана через SMIL `<animateTransform from="0 0 0" to="360 0 0">` — явный центр.
